# Build to Survive engine (bts-engine)

Makes 45–65 s vertical Shorts (1080×1920, 30 fps) in the channel's illustrated 2.5D isometric "build it layer by layer" look.
Voice: Kokoro `am_michael` at speed 1.08. Music, whooshes, dings and the end chime are generated by code.
`example_windcatcher.py` is the pilot video (#1) and the reference for style and pacing: read it first.

## Run
```
bash SETUP.sh                      # once per machine (voice model + fonts)
mkdir ~/short1 && cd ~/short1      # write script.py here
python3 ~/btseng/tts.py            # -> vo/  (prints TTS_DONE and the seconds of speech)
python3 ~/btseng/render.py --frames 0,8,20,35,50   # stills: frame_XXX.X.png  (LOOK at them, fix, repeat)
python3 ~/btseng/render.py         # -> short_v.mp4 + events.json
python3 ~/btseng/audio.py          # -> short.mp4 (final, -14 LUFS, metadata stripped)
python3 ~/btseng/cover.py          # -> cover.jpg (frame 0 = title card), optional
```
Re-running tts.py only makes the missing lines; delete `vo/` after changing any line's words.

## script.py
```python
TITLE = ["YOU BUILD A", "WINDCATCHER"]   # 2 caps lines shown over the opening beat (line 2 big + yellow, <= 12 chars ideal)
SKY = "#2F8FCB"                          # background (night stories: "#1B2A4A"; snow: "#6FA8D6")
KEYWORDS = ["tower", "wind", ...]        # words shown yellow in captions (label words and numbers are automatic)
B = [ beat("Spoken line.", obj, obj, ...), ... ]   # 11-14 beats, 120-150 words in total
```
Each `beat()` is ONE narration line (1–2 short sentences) plus the objects that pop in while it is spoken. Objects stay
on screen (the build grows) until `remove("id")`. Giving a new object the SAME id replaces the old one (white arrows ->
red arrows). Beat 0's objects are drawn complete from frame 0 (frame 0 is the cover).

### World
x runs to the screen's lower-right, y to the lower-left, z up. A scene is usually a 10×10 ground block at (0,0).
Only the +x side (right) and +y side (left) of things are visible, so put cut-away details on those faces.

| helper | use |
| --- | --- |
| `ground(x,y,w,d, style, depth)` | cut-away earth block; style grass, desert, savanna, jungle, snow, rock, beach |
| `box(x,y,z,w,d,h, color, top=None)` | walls, towers, blocks, platforms, steps, boats' hulls |
| `room(x,y,z,w,d,h, wall, floor)` | cut-away building: floor + 2 back walls so the inside is visible |
| `roof(x,y,z,w,d,h, color, style)` | pyramid, gable_x, gable_y, flat (z = top of the walls) |
| `cyl(x,y,z,r,h,color)` / `cone(...)` | round towers, trunks, tanks, wells / mounds, piles, volcano |
| `water(x,y,z,w,d)` | flat water with ripples (pools, rivers, sea) |
| `side_patch("y"|"x", a, b, z0, z1, color)` | paint on the ground block's side: tunnels, channels, burrows, roots, pipes underground |
| `poly([(x,y,z),...], color)` | any flat 3D shape: slits, doors, ramps, sails, bridges, boats |
| `line3([(x,y,z),...], color, width)` | ropes, roots, poles, cables (smoothed) |
| `arrows([(x,y,z),...], color, width)` | animated flow: wind, air, water, path. WHITE neutral, red `#E74C3C` hot/danger, blue `#4FC3F7` cool/water |
| `tree(x,y,z,size,kind)` | round, pine, palm, bamboo, bush, fig |
| `figure(x,y,z,size,pose)` | OUR MASCOT (faceless, mustard-yellow jacket). size 1.5–1.8 reads well. poses: stand sweat cheer work sit scared walk |
| `critter(x,y,z,size,kind,color,n,spread,face)` | insect, ant, quadruped, bird, fish, rodent, crab; n>1 = a swarm/herd |
| `rock(x,y,z,size,color)` | rocks, stones |
| `label(text, x,y,z, dx, dy)` | yellow tag + leader line pointing at a part (1–2 words). Remove it a beat or two later |
| `measure(x,y,z0,z1,"28 M", side)` | white measuring line + big number: THE number moment of the video |
| `counter("15 YEARS")` | big yellow card in the middle (temperatures, years, counts) |
| `sun()`, `clouds(n)` | sky decoration (put in beat 0) |
| `fx(kind)` | heat, rain, snow, wind, night, sparkle (final beat), dust. `remove("fx_rain")` stops it |
| `focus(x,y,z,zoom)` | camera pushes in on a point for this beat (zoom 1.3–1.6) |
| `overview(zoom=None)` | camera back to everything (the default each beat is auto-fit) |

Draw order is automatic (back to front); if something hides wrongly add `zi=<number>` (bigger = drawn later).

## The formula (every video)
1. Hook line: "You…"/"If you…" puts the viewer in the problem (beat 0, under 12 words, no greeting).
2. Simple first fix → it isn't enough ("But…").
3. 4–6 "But… so you add…" upgrades; each upgrade = a new object popping in + a label.
4. One number moment (`measure` or `counter`) with a real, sourced number.
5. Pull back on the finished build.
6. Last line: "Congratulations, you just built a ___." + one real-world twist (who does this, where), `fx("sparkle")`, `overview(0.9)`.
Every fact and number must come from a source read in this run. No weapons, no gore, no animals hurt on screen.

## Look checks before the full render
Look at frame 0 (it must show the title and a complete, striking scene), and a frame from each third.
Labels must not cover the build; the mascot must be visible; arrows must read clearly; nothing important below y=1350
(captions and the Shorts buttons live there).
